What it will not do

It never invents an anecdote, a figure or a quote to make a text sound lived-in. If a concrete detail would help, it suggests one in a separate section, for you to fill in if you have it.

Kept, and flagged

The LinkedIn post moves an application to .NET 8. That is the author's choice, so the rewrite keeps it. But .NET 8 left Microsoft support on 10 November 2026, so the skill flags it under “Facts to check”, with the source and a ready-to-use alternative.

Honest limits

  • The score is indicative. It counts patterns; it is not an AI detector.
  • Fact-checking needs a web search tool. Without one, dated facts are flagged as unverified.
  • With web search, the model without the skill also caught the .NET and Python facts, and also dropped the obvious tics. The skill guarantees the format, not the instinct.
  • It costs about 15 % more tokens and 30 to 45 seconds more per text.
  • Voice matching is only as good as the samples you give it.

Install the plugin

In Claude Code, two commands.

Then paste a text and say it sounds like AI, or call /text-humanizer:text-humanizer-en for an English text, /text-humanizer:text-humanizer-fr for a French one. On Claude.ai or another agent, download the English or French skill folder, zip it and upload it as a skill.
